HTML

Généralité

Le fichier HTML est la base d'une page de site web. C'est la que se trouve l'essentiel du contenu que l'on veux afficher, que ce soit du texte, des image, etc. Dans un fichier HTML, on utilise des balises pour organiser le contenu. Tout ce qu'on va écrire sur la page devra d'une manière ou d'un autre être quelque part entre des balises. Une balise est un mot clé entre deux chevrons, comme par exemple <body>, <span>, <div>, etc. Il en existe tout plein et l'apprentissage du HTML consiste principalement à connaître le mieux possible ces balises et comment elles fonctionnent, même si en pratique, une petite partie d'entre elles sera suffisante pour faire 80% du travail, et d'autres seront plus rares et très spécifique.
